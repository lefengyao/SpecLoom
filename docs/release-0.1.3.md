# SpecLoom 0.1.3

面向 Windows PC 的工作区更新，独立桌面版和 Trailblazer Hub 模块使用同一份功能实现；模块需要 Hub 0.1.6 或更新版本。

## 页面切换与组件分类

- 页面首次访问后保留编辑状态和会话订阅；返回时直接显示已有内容。
- 左侧导航支持收起为图标栏；保留悬停名称和键盘访问，记住展开状态。
- 资料目录不再随分类切换重复读取；组件内容按文件版本复用。
- 组件列表、项目树和实体组件选择器使用“官方组件 / 自定义组件”。内置状态机按其原始文件身份识别；复制、新建和已有用户资料属于自定义组件。
- 项目切换重建页面，避免跨项目混用内容。资料草稿和版本冲突检查继续保留。

## 工具链和侧栏

- 每轮思考、活动和工具记录收纳到固定高度的方框，内部滚动；调用状态和统计仍可直接查看。
- 点击“展开”或工具名称，在右侧栏查看参数、结果和复制操作。
- 侧栏提供工具链、会话概览和扩展栏目接口；窄窗口以抽屉显示，支持 Esc 关闭和键盘导航。
- 审批请求和问答继续独立显示在对话中。

## 引导智能体

1. 智能体运行或等待期间，在输入框发送补充要求，文字会暂存在输入框上方。
2. 点击“引导”立即加入当前运行；当前回复不会被中断，在完整回复或工具批次结束后纳入后续工作。
3. “修改”把内容放回输入框；“删除”移除暂存内容。
4. 当前运行结束时，未引导的内容自动回到所属会话输入框，保留新输入的草稿。

引导记录带有运行身份和唯一消息身份：过期运行拒绝新引导，相同引导重试不会重复发送。切换会话、重新打开页面或连接失败时，未发送文字保留；已接受的文字仍在历史中。

## 验证

真实 Electron 桌面测试覆盖运行中切页、当前运行连续处理引导、未引导文字回填、组件分类、导航收缩和侧栏。最后一次测试项目的已访问页面切换中位耗时 32.9 ms，P95 为 34.0 ms（点击后等待两帧绘制，包含绘制等待）。这不是首次启动、首次目录加载或所有规模项目的耗时承诺。

还修复了会话创建完成时临时输入向新草稿交接的竞态，避免快速输入漏掉字符。

验证记录：

- TypeScript 类型检查和 ESLint 通过。
- 完整单元与集成测试：1140 项通过、14 项跳过。跳过项依赖外部 Python、Godot 或 Docker 环境；本机 Docker 服务不可用。日志：`.local/full-unit-0.1.3.log`。
- 后续输入交接和导航调整的 Renderer 专项：91 项通过；窄窗口抽屉调整后导航专项：33 项通过。日志：`.local/final-renderer-0.1.3.log`、`.local/final-navigation-0.1.3.log`。
- Electron 完整端到端测试：18 项通过。最后修复 900 像素窗口的收缩样式后，审批、引导和导航的 3 项受影响回归测试通过。日志：`.local/full-e2e-0.1.3.log`、`.local/final-width-e2e-0.1.3.log`。
- 会话创建期间的快速输入回归连续重复 15 次通过。
- 实际 Windows 便携包启动验证通过：检查版本、9 个发行文件的内容一致性、隔离运行配置、组件分类、引导 API 和导航收缩；无 Renderer 错误。日志：`.local/verify-packaged-0.1.3.log`。
- 实际 Hub 0.1.6 发行版安装模块验证通过：下载页导入、启动、运行中引导、PDF 工具、导航收缩、设置和草稿保留、单实例、关闭 MCP、卸载重装以及 StoryFabric 兼容性。引导保持同一运行且不中断回复，无 Renderer 错误。结果：`../TraiblazerHub/.codex/verification/specloom-module-0.1.3-packaged-result.json`。
