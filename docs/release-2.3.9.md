# SpecLoom 2.3.9 更新

资料分组树支持展开与收起，并把资料直接挂在分组下面。

## 分组树

- 每个装了资料的分组现在都有折叠箭头：展开后在该分组下列出它的资料，点击资料即在右侧打开。
- 分组下面同时有子分组和资料时，先列子分组、再列资料；收起父分组会一并隐藏。
- 展开的分组用打开状态的文件夹图标区分。
- 「未分组」也可以展开查看其中的资料。
- 「全部资料」保持为汇总入口，不展开具体列表，避免与整棵树重复。

## 其他树形列表

- 工作台「添加组件」对话框里的分组区块改为可折叠：点击分组标题即可收起/展开该组组件，标题行显示数量。
- 资料页原有的资料树、资料层级列表、关系图与图标视图原本就支持折叠，保持不变。

2.3.8 的「自动整理」按钮与 2.3.7 的居中布局保持不变。
