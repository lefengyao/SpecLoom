# SpecLoom 2.3.5 更新

修复实体工作台不画挂载关系的问题：`mount` 之前只进入卡片文案，没有参与连线构建。

## 画布连线

- 组件通过 `mount.parent` 挂在另一个组件上时，连线从**父组件**指向该组件，并在边上标注锚点名（例如 `slot_1`）。
- 挂在实体自身（`mount.parent: "__entity__"`）或没有 `mount` 时，仍然从本体指向组件，行为与之前一致。
- 组件卡片新增四个 source 连接点，支持组件到组件的边；原有的 target 连接点与自定义锚点保持不变。
- 连线的出入边按两张卡片的相对位置选择（左右或上下中更近的一侧），不再固定以本体为参照。

## 回退

- 父组件不存在、`mount.parent` 指向自身、或父组件未在本实体绑定时，边回退到本体，画布仍然可读；这些情况由校验器报 `MOUNT_PARENT_UNKNOWN` 等错误，而不是静默画错。

2.3.4 的挂载锚点模型与校验、2.3.3 的布局保存修复保持不变。
