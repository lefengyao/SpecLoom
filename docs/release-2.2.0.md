# SpecLoom 2.2.0 更新

2.2.0 把外部 MCP 调整为“直写原项目”，并让连接凭据按项目固定；同时收尾任务、入口和络络页的交互。

## 外部 MCP

- `files.write` / `files.patch` 直接写入项目磁盘，不再进入 staged 变更集；任务读写范围仍然校验，修改已有文件仍要求先读取当前版本。
- `bash.exec` 直接在项目根目录用 Git Bash 执行，不再创建快照；输出、超时和取消行为保持不变。
- 变更审查改为只列出“已直接修改的文件”（新增/修改/删除）；直写任务可在审查面板直接「标记完成」。
- 空变更集提交会真正结束任务，不再卡在 staged。
- `changes.preview` 返回直接修改的文件列表；`changes.commit` 对直写任务只做收尾。

## MCP 连接

- 令牌和端口按项目持久化：同一项目重启后连接地址不变，只有手动「刷新令牌」才会换；端口被占用时才回退到新端口并记录。
- MCP 页新增「刷新令牌」，刷新会断开现有客户端。
- MCP 任务卡支持「移除任务」；删除任务绑定的会话会连带删除任务。

## 任务与界面

- 任务范围表单移除「提交模式」；可写文件树改为独立 memo 组件，大项目输入任务名称不再卡顿。
- 入口页、MCP 任务卡、范围编辑等沿用 2.1.0 的两栏与会话入口布局。
- 络络页海报按窗口高度自适应缩小、居中并留白，无需滚动即可完整查看。

## 校验

- 文档类变更跳过 Godot 导入；有 staged 变更时才建快照。
- 校验优先使用设置中的本地 Godot；未配置时回退 Docker。
- 快照上限 8GB、单文件 1GB，Godot 超时 300 秒。
