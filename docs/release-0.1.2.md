# SpecLoom 0.1.2

发布日期：2026-10-09。Windows x64 安装包与便携 ZIP 包含当前工作区的最新源码，以及此前完成的模型恢复、资料管理、长任务和工具审批改动。

## 本次优化

- 会话快照直接比较正文与结构化字段，复用未变的历史记录，减少长对话更新时的 JSON 序列化和重复合并。嵌套答案、统计和审批状态有变化时仍正常更新；旧版本快照仍被忽略。
- 时间线按用户轮次预先计算回复和详情，避免对同一轮的大量工具记录逐项重复扫描；输入变化时复用分组结果。
- 删除会话时取消待执行的草稿保存，忽略删除后迟到的保存结果和流式快照，避免会话重新出现。删除失败时保留草稿并继续保存。

本版同时包含发送后清空输入框、断流最多五次重试、取消工具轮次上限，以及“请求批准 / 帮我批准 / 完全访问”三种会话权限。

## 性能测量

使用同一台电脑、220 项历史、约 3 MB 的固定数据，执行 40 次快照更新，排除前 5 次预热。计时只包含历史合并，不包含 IPC、磁盘读写或整页渲染。

| 单次历史合并 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 中位数 | 4.55 ms | 0.31 ms |
| P95 | 5.13 ms | 0.42 ms |

1500 项工具记录的已完成轮次新增了线性扫描回归；未变化的历史正文继续保持对象复用和 Markdown 解析复用。这些结果来自固定样本，不代表整应用或所有设备具有相同加速比例。

- 独立代码复查未发现本次修改的阻断问题。

模型验收使用本机模拟端点；未调用真实供应商或修改用户原有配置。安装包已构建并核对版本资源，未自动覆盖用户已安装的版本。
