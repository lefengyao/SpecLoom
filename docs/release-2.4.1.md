# SpecLoom 2.4.1 更新

补齐挂载模型的两个缺口：现在可以在界面里挂载，锚点也会沿继承链传下来。

## 在检查器里挂载

- 组件检查器新增「挂载」区：先选父级（实体本身，或已绑定且声明了锚点的组件），再选锚点。
- 选「不挂载」即清除该组件的挂载关系。
- 父级列表只列出真正声明了锚点的对象，避免选出必然报错的组合；组件不会出现在自己的父级选项里。
- 继承来的挂载改动会生成本实体的显式覆盖，与字段覆盖的规则一致。

## 锚点继承

- 组件的 `anchors` 现在沿 `extends` 链继承：基类声明的锚点，派生组件可以直接被挂载。
- 同名锚点由派生组件覆盖，顺序仍是基类在前。
- 校验器按继承后的锚点判断 `MOUNT_ANCHOR_UNKNOWN`，工作台卡片也显示继承来的锚点。
- 基类缺失或成环时仍按原规则报错，同时保留能读到的锚点。

## 兼容

- 已有实体没有 `mount` 时显示「不挂载」，行为不变。
- 2.4.0 的系统/功能/架构决策与 2.3.x 的布局功能保持不变。
