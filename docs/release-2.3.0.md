# SpecLoom 2.3.0 更新

本轮加入组件之间的字段继承、资料配图裁剪，并修复两处实际使用中暴露的问题。

## 组件继承

- 组件可以 `extends` 另一个组件：有效字段 = 基类字段顺序 + 派生新增字段，同名字段由派生类原位覆盖。
- 实体 `extends` 仍然只能指向实体；画布连线仍是实体 → 组件绑定，不做组件之间的连线。
- 不继承 `notes`、`scope`、`description` 或正文，只合并字段与默认值。
- 组件资料页新增「组件继承」区块与「继承字段」列表，可一键把基类字段「覆盖」为自身字段；覆盖后基类再改不会自动同步。
- 有组件子类时锁定已存在字段的名称/类型/删除，并提示哪些组件依赖。
- 工具面同步：`MaterialRead` 返回继承后的有效字段；`MaterialBindComponent` 用有效字段补默认值并校验类型；`MaterialCreate` / `MaterialUpdate` 拒绝成环或缺失的继承目标。校验器新增 `COMPONENT_INHERIT` 与 `COMPONENT_INHERIT_CYCLE` 诊断。

## 配图裁剪

- 资料配图旁新增「裁剪」按钮：在图片上拖拽框选，应用后另存为新图片并切换引用。GIF 因可能含动画而禁用。
- 裁剪结果统一转为 WebP；动画 WebP 只保留当前帧，对话框内有提示。
- 外置智能体的 `MaterialSetImage` 支持 `crop`（归一化 `x/y/width/height`）：`sourcePath + crop` 直接裁剪导入，`imagePath + crop` 另存为新图并切换引用；`crop` 不能与 `remove` 同用，越界与 GIF 会被拒绝。

## 其他修复

- 「关于项目」页 Git 分支表头此前引用了不存在的变量，回退成深色底 + 深色字；现改为 `--bg-sunken` + `--text-muted`，浅色、深色、纸感三套主题统一使用这两个变量。
- 大图上传的 WebP 压缩改为「质量档位用尽后按实测体积比例缩边」：12MP 高熵图片不再因 14 次尝试耗尽而报「图片压缩后仍超过 2 MiB」，普通照片仍保持原来的质量优先策略。
- 组件继承后，实体绑定组件时的字段白名单与类型校验改用继承后的有效字段。

2.2.3 的外置 MCP `skills.load` 修复、2.2.2 的 Hub 插件后端修复保持不变。
