# SpecLoom 2.9.2 更新

系统页补上工作台，形态与实体工作台一致。

## 系统工作台

- 三栏布局：左侧系统列表、中间画布、右侧挂载检查器。
- 画布以系统卡片为中心，挂载的组件（含决策树）作为卡片铺开；有 `mount.parent` 时从父组件连边并标注锚点，否则从系统连边。
- 检查器可改实例 `key`、编辑组件字段、为 `decision_tree` 选择决策树、移除挂载。
- 「添加挂载」打开组件浏览器（含继承后的字段），新增实例自动分配 `key`（如 `decision_tree_1`）。
- 「自动整理」按挂载层级重排卡片；拖动位置按项目与系统分别记忆。
- 保存只写回 `mounts`，其它字段（总线、事件、signals、dependsOn）原样保留。

## 页面

- 「系统」页面与「实体」页面同构：工作台 / 详情 / 源码三个视图共用同一份草稿。
- 详情与源码复用原有资料编辑器，因此音频总线、事件、结构化关联仍在原位置编辑。

## 兼容

- 实体工作台行为不变；两套工作台各自保存布局，互不影响。
