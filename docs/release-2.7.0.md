# SpecLoom 2.7.0 更新

决策树的条件节点改为「选实体 + 选组件 + 选字段」，与给实体装组件同一套查找方式。

## 条件编辑

- 条件类型二选一：字段比较 / 事件名。
- 字段比较时，检查器提供四个选择器：
  - **引用实体**：默认「当前实体」，也可以挑项目里任意实体，表示读取那个实体上的组件
  - **组件**：按「官方组件 / 自定义组件」分组列出全部组件，和实体工作台的组件库同源
  - **字段**：跟随所选组件，列出继承后的有效字段，显示字段标题
  - **运算符 + 值**：运算符限定 `<= < >= > == !=`；值按字段类型给数字输入、布尔下拉或文本
- 改动会用统一的拼接规则生成比较式，并在下方显示最终文本，方便直接核对 YAML。
- 事件名分支只保留事件输入，不允许再写引用实体。

## 引用校验

- `owner` 指向的实体必须存在，否则 `TREE_OWNER_UNKNOWN`
- 该实体必须挂载了条件里引用的组件，否则 `TREE_OWNER_COMPONENT_MISSING`
- 只有字段比较可以写 `owner`；事件条件带 `owner` 会报 `TREE_CONDITION_INVALID`
- 组件、字段、字面量类型仍按原规则校验

## 兼容

- 已有只写 `component.field op value` 的比较式继续有效（`owner` 省略即为当前实体）。
- 2.6.1 的反查与决策编号校验保持不变。
