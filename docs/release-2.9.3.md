# SpecLoom 2.9.3 更新

系统工作台的「添加挂载」换成与实体工作台一致的组件浏览器。

## 组件浏览器

从实体工作台抽出共享组件 `ComponentBrowserDialog`，系统工作台直接复用同一形态：

- 左栏「收藏」「最近使用」（按项目记忆）
- 顶部搜索、收藏星标
- 「匹配项 · N」与筛选（全部 / 未添加 / 已继承 / 已添加）
- 按分组列出组件，组内按继承关系缩进嵌套，分组标题可折叠
- 已添加 / 已继承徽标
- 下方「描述」区：说明、路径、正文预览、分组 / 继承 / ID / 范围 / 字段数，以及字段清单与默认值
- 底部「添加 / 取消」；双击条目也能直接添加

系统侧的行为：已挂载的组件标为「已添加」，双击或点「添加」后按 `决策树_1` 这类规则分配 `key`，随后可以在画布上编辑。

## 说明

- 实体工作台仍使用原有内联对话框，行为未变；两者外观与交互一致，后续可以合并为同一实现。
- 系统工作台原有的简易弹窗样式已移除。
