# SpecLoom 2.6.1 更新

补上反查与决策编号唯一性校验。

## 反查（「被引用」）

资料详情新增「被引用」区块，从其他资料反向列出引用方：

- **组件**：被哪些实体/地图绑定、被哪些系统引用、被哪些决策树的比较式使用
- **系统**：被哪些功能关联、被哪些架构决策标记为影响范围
- **决策树**：挂载在哪些实体上、挂载在哪些系统上（含 `key` 区分后的实例）
- **功能 / 架构决策**：各自关联的系统仍然在结构化编辑区里查看

改名前先看这块，能直接知道影响范围；列表显示标题与 id。

## 决策编号唯一

- `specs/decisions/` 下两份文件使用相同四位编号时报告 `DECISION_NUMBER_DUPLICATE`，并指出先占用该编号的文件。
- 编号与文件 `id` 仍相互独立校验（`id` 重复走 `SPEC_ID_DUPLICATE`）。

## 兼容

- 反查只读取已加载的资料摘要，不额外读盘；资料很多时也不会明显变慢。
- 2.6.0 的决策树工作区与挂载模型保持不变。
