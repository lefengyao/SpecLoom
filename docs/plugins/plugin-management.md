# 插件管理

左侧「插件」页面管理当前打开的 Godot 项目。顶部的 **SpecLoom Godot MCP** 卡片显示安装、启用、连接和版本状态，并可定位插件目录。安装并启用、重新启用都会先显示确认；禁用直接移除启用项。确认后重新载入 Godot 项目才能生效。该官方插件不重复出现在普通项目插件列表中，完整安装、迁移和工具说明见 [SpecLoom Godot MCP](godot-mcp.md)。

项目插件列表只扫描 `addons/<目录>/plugin.cfg`，显示插件名称、说明、作者、版本和启用状态。可以按名称、说明、作者或目录搜索，也可以筛选启用、禁用和异常项。损坏的元数据仍显示目录名；已经失效的启用引用可以移除。只有配置有效的插件可以启用。页面可在文件管理器中定位项目或插件目录。

切换普通插件只修改 `project.godot` 中完全匹配的 `res://addons/<目录>/plugin.cfg` 引用，并检查配置语法与文件版本。遇到并发修改或不支持的配置时会停止。SpecLoom 不执行、安装、卸载或删除第三方插件文件。

扫描最多处理 512 个直接子目录、每个 `plugin.cfg` 64 KiB、`project.godot` 1 MiB 和 1,024 个启用引用。符号链接、junction、路径遍历和不安全目录会被排除。
