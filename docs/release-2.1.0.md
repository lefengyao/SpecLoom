# SpecLoom 2.1.0 更新

2.1.0 聚焦入口页与任务范围体验：让最近项目成为主区域，让“任务”与 MCP 的关系更直观，并把范围选择从手填路径改成勾选项目文件。

## 入口页

- 入口页改为左右两栏：左侧是吉祥物、问候、名称与「打开项目 / 创建示例项目」，右侧整块显示近期项目。
- 左侧主按钮压底，近期项目列表在右侧内嵌框内滚动；窄窗口自动上下堆叠。
- 打开或切换项目、创建示例项目时显示加载遮罩与“正在加载项目…”提示，慢加载不再像卡死。
- 没有任何近期项目时，品牌区居中显示。

## 任务与 MCP

- MCP「连接 SpecLoom」页新增显眼的「MCP · 调用任务」区块：直接展示任务 ID、复制按钮和“外部客户端调用时作为 taskId 传入”的说明。
- 该区块支持在项目任务之间切换；没有任务时可直接新建任务。
- 当前会话绑定的任务会自动同步为“当前任务”，新建任务后无需再手动点一次会话。
- 「新建任务」从右上角移入会话栏，位于会话「＋」旁边。

## 任务范围

- 任务创建后可以重新编辑范围：会话的「已授权范围」旁新增「编辑范围」，运行中的任务不可修改。
- 范围选择改为项目文件勾选树：文件夹与文件均可勾选，支持半选、筛选、全选与清空，默认全选。
- 勾选结果自动压缩为 `目录/**` 与具体文件路径；手动填写模式保留在「高级」中。
- `*` 现在也可以作为可写路径，表示整个项目可写；提交模式仍默认“手动审查”。

## 质量

- 新增任务范围更新的核心测试与范围编辑 UI 测试，相关测试套件全部通过。
- 类型检查通过。
