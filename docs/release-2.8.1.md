# SpecLoom 2.8.1 更新

对 2.6–2.8 的决策树做了一轮审查，修掉发现的问题。

## 修复

- **添加子节点**：叶子节点、已经有子节点的修饰节点不再允许点击（此前可点但无效果），悬停给出原因。
- **树本身可编辑**：工作区新增「名称」「说明」输入；改名称时同步更新正文一级标题，不必为了改标题切回源码模式。
- **布局保存去抖**：拖动过程中不再逐帧写 localStorage，停手约 250ms 后写一次。
- **决策树页面宽度**：进入决策树类别时自动收起资料列表，画布获得完整宽度；需要时从工具栏重新打开。
- **非条件节点残留条件字段**：动作/组合节点上写 `comparator`、`event`、`signal`、`owner` 现在报 `TREE_NODE_INVALID`，不再被静默忽略。
- **系统 `mounts` 结构**：按组件绑定规则校验（允许 `- 组件id` 短形式，但 `values` 必须是映射）。
- **信号**：重复声明同名信号报 `SPEC_FIELD_INVALID`；地图不再允许声明 `signals`（摘要也不收录）。

## 文档

决策树设计文档补充 2.7 / 2.8 的追加说明（实体引用、信号来源、互斥规则、去抖保存）。

## 说明

- 删除节点仍会连同子树一起删除，且没有撤销；这需要一套撤销栈，留作独立功能。
- 决策树暂不支持内嵌引用另一棵树，与设计一致。
