# SpecLoom 2.3.1 更新

本轮包含 Git 变更页的差异着色与批量暂存、实体工作台的尺寸与防重叠改造，并修复任务读取与资料页保存之间的版本冲突。

## Git 变更

- 差异按行着色：新增行绿底、删除行红底、`@@` 块头加粗、`diff --git`/文件头等元信息弱化，浅色、深色、纸感三套主题各自适配。
- 变更面板每行新增复选框，表头「全选」带半选状态，旁边显示已选数量。
- 新增「暂存所选 / 取消暂存所选」：批量暂存只提交仍未暂存的文件，批量取消只提交已暂存的文件；刷新后自动移除已消失文件的选中状态。单行暂存按钮保留。

## 版本冲突修复

- 修复在会话/任务工作区读取文件（例如点 Skill 加载来源）时，报 `A dependency was read at incompatible versions` 的问题。原因是资料页保存直接写盘、不经过任务，任务持有的读取基线过期后再次读取即冲突。
- 现在只有**已暂存**的改动才保留旧版本基线并拒绝版本变化；普通读取会把基线推进到最新版本，冲突不再拦阻正常浏览。

## 实体工作台

- 组件卡片新增 `size` 属性，尺寸由实际渲染测量后写入布局；实体卡片自身也记录尺寸，其左上角固定为画布原点。
- 组件位置与实体位置统一表示**左上角**；旧的居中坐标会在加载时自动平移迁移，构图保持不变。
- 默认布局按卡片尺寸装入实体左右两侧，间距 24px，默认不再重叠。
- 拖动时与实体或其他组件相交会显示红色描边；松手仍重叠时自动落到最近空位。
- 画布新增「自动整理组件」按钮，按实测尺寸一键重排。

## 其他修复

- `git.css` 与 `usage.css` 的错误提示样式引用了不存在的颜色变量，导致边框与文字颜色失效；改用项目实际的危险色令牌。
- 2.3.0 的组件继承、配图裁剪与大图压缩收敛修复保持不变。
