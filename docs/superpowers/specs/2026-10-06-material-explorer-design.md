# 项目资料资源管理器

用户目标：实体、组件、地图、设定和 UI 创建后直接保存、留在各自页面；随时查看，支持配图、分组、列表与图标显示。资料编辑与智能体任务解耦。

## 行为

- 创建成功即发布独立 Markdown/YAML 文件；保持当前页面并选中新资料。创建失败保留输入。
- 编辑使用“保存资料”，不创建任务、不进入工作区；外部修改触发版本冲突并保留本地编辑。
- 常驻浏览区域提供搜索、分组筛选、列表／图标视图；详情提供分组名称与已有分组建议。分组独立于父级和继承关系，清空名称即移出分组。
- 保留已有层级关系树、原型继承与组件字段编辑。分组不会改变物理路径和组件引用。
- PNG/JPEG/WebP/GIF 图片通过上传复制到 assets/specloom/materials，以内容摘要命名；资料 image 字段保存相对路径。图片预览由主进程安全读取。单张最多 2 MiB。

## 边界

- ProjectDocuments：普通人工资料读写、内容检查、版本锁及图片资产。复用 FileStore 的路径规则和原子写入，不依赖智能体、模型、会话或审查任务。
- MaterialExplorer：搜索、分组筛选、视图切换与选择；仅消费资料摘要。
- MaterialImage：上传、加载与展示图片。
- DocumentsView：协调浏览、选择与编辑；App 提供项目身份与草稿缓冲，不再提供任务暂存回调。

## 验证和清理

保存请求绑定项目路径，防止切换项目后写入错误项目。新建使用 absent，更新使用读取版本。结构化资料检查字段，并阻止本次编辑新引入的引用错误；已有其他资料的错误不阻断无关编辑。失败保留草稿和编辑器。

保留所有前序源码、设计资料、发布包和用户数据。整理生成目录忽略规则，仅清理确认可再生的旧测试输出。通过核心、IPC、Renderer 回归和源码 Electron 验收确认创建、持久化、浏览、图片与分组。
