# SpecLoom 一分钟宣传动画设计（02 / 风格）

日期：2026-10-21
状态：方向 S1 已确认，三张风格帧已实测通过。
上游文档：[2026-10-21-specloom-promo-animation-design.md](2026-10-21-specloom-promo-animation-design.md)（内容层）。
本文范围：**只定视觉**（色、字、网格、线条、转场、动效）。镜头表是下一阶段产物。

## 方向

**S1《产品规格书》，只从 S2 借一处对撞。**

纸就是唯一的界面：纸白底、双层蓝图网格、1px 墨绿直角线、等宽标注、`FIG.` 编号。没有 3D、没有景深、没有渐变。动效只有三件事——线在画、框在落位、字在打。

唯一的例外是第 4 拍扫描段落的 60 帧：纸白短暂沉到墨绿，代码浮出来，再合回纸面。借这一处的视觉高潮，不背第二套视觉资产的成本。

理由：官网 `website/` 与应用已经用同一套纸墨语言，片子必须一眼是 SpecLoom。S2 要维护纸 + 深色 UI + 场景三套东西，S3 会丢掉已经攒下的品牌资产。

## 色板与用法

| 层 | 色值 | 只用于 | 禁止 |
| --- | --- | --- | --- |
| 底 | 纸白 `#edf1e8` | 全片底色 | 不用作文字色 |
| 面 | 纸面 `#f7f9f3` | 卡片、输入框、面板填充 | 不得占满整屏 |
| 墨 | 墨绿 `#14352a` | 主文字、线条、图示、CTA 底 | — |
| 主 | 织绿 `#1f6f54` | 强调、路径标注、扫描线、节点点亮、已读标记 | 不做大面积填充；**不进深色底** |
| 索引 | 赭金 `#a9762e` | 边框、图形、指示块 | **不作文字色**（见下） |
| 索引（文字） | 深赭 `#8a5f22` | 编号、小标签、关键数字 | — |
| 次要 | 灰绿 `#596b61` | 说明、元信息、页眉页脚 | — |
| 精灵 | 精灵绿 `#239d7c` | 络络本体；**深色底上的唯一强调色** | 不进纸面 UI |

**核心规则：金色永远是指示，不是装饰。** 一帧里金色元素不超过 2 处，超过就失效。

## 三处实测定下的修正

这三处不是审美选择，是量出来的：

| 问题 | 原值 | 实测 | 修正 |
| --- | --- | --- | --- |
| 赭金作小字 | `#a9762e` | 对纸面 **3.45:1**（15–20px 需 4.5） | 文字改用深赭 `#8a5f22` = **4.91:1**；图形与边框仍用 `#a9762e` |
| 次要文字直接沿用官网灰 | `#8b9c92` | 对纸面 **2.64:1**，视频压缩后基本消失 | 改用 `#596b61` = **4.96:1** |
| 织绿用在墨绿底上 | `#1f6f54` | 对墨绿 **2.20:1**，完全读不出 | 深色底强调改用精灵绿 `#239d7c` = **3.93:1** |

第三条的副作用是好的：对撞段只有 `180` 一个精灵绿强调，深色画面的信息层级反而更干净。

## 字体与字号（1920×1080 实测）

| 角色 | 字号 | 行高 | 字重 |
| --- | --- | --- | --- |
| 主标题（两行） | 132px | 1.06 | 700 |
| CTA 按钮文字 | 32px | — | 600 |
| **旁白字幕** | **44px** | 1.5 | 500 |
| 说明行 | 38px | 1.5 | 400 |
| 卡片标题 | 40px | 1.2 | 700 |
| 字段值 | 30–34px | 1.4 | 600 |
| 路径 / 标注（等宽） | 17–20px | 1.3，字距 0.04em | 400 |
| 图内编号（等宽） | 14–16px | 1 | 400 |

主标题沿用官网断行「让 AI 读懂 / 你的游戏世界。」，第二段用织绿。**实测两行占 915×280px，版心 1020px，余量 105px**——不需要缩字号。

中文字体用系统栈（Microsoft YaHei / PingFang SC）；路径、代码、编号用等宽（Cascadia Code / Consolas）。不引入网络字体。

## 网格与线条

- 双层网格：24px 细线 `rgba(20,53,42,.05)` + 120px 主线 `rgba(20,53,42,.10)`。深色帧反相为 `rgba(237,241,232,.035)` / `.07`。
- 版心：左右各 120px，上下各 80px。页眉页脚线在 60px 处，`rgba(20,53,42,.18)`。
- 线条恒为 1px `rgba(20,53,42,.26)`；连接线用虚线 `5 4`，走向走直角，端点加 3.5px 织绿圆点。
- **一律直角。** 卡片 = 纸面填充 + 1px 边框，无阴影、无圆角、无模糊、无渐变。
- 只有两个例外允许曲线：文字光标、络络本体。
- 已读标记：卡片顶部 3px 织绿条。这是全片唯一表达「这份资料读过了」的手段。

## 转场语言（全片只用两种）

1. **对位平移** — 新旧画面共享一个视觉锚点（一张卡片滑出，原位长出一个框），整体平移 80–160px 后换底。用于拍 2→3、拍 4→5。
2. **裁切揭示** — 一条 1px 织绿线扫过，线右侧内容被替换。用于 0:14 图纸铺开、0:44 分屏、0:52 收束。

**不用**：淡入淡出（太软，破坏图纸感）、3D 翻转、缩放弹跳。

## 动效节奏

| 动作 | 时长 | 曲线 |
| --- | --- | --- |
| 卡片/框落位 | 18 帧 + overshoot ≤ 2px | `cubic-bezier(.22,.61,.36,1)` |
| 线在画 | 24–36 帧 | linear（`stroke-dashoffset`） |
| 字在打 | 逐字 2 帧 stagger，总 ≤ 20 帧 | linear |
| 扫描线 | 4 张卡共 36 帧，单帧位移 6px | ease-in |
| 节点点亮 | 间隔 6 帧，单节点 10 帧 | ease-out |
| 深色对撞进出 | 进 8 帧 / 出 8 帧 | ease-in-out |

**全片没有任何单一动画超过 40 帧。** 图纸感靠「手快」，不靠慢镜头。

## 那一处对撞

仅 0:32–0:34，共 60 帧：

1. 卡片翻面露出字段（纸面）
2. 背景 8 帧沉到墨绿 `#14352a`
3. 代码行以等宽 38px 浮出，`180` 用精灵绿
4. 8 帧合回纸面

硬规则：**全片只此一次**，其他任何位置都不出现深色底。

## 吉祥物边界

只在 0:30（睁眼，320px 高，扫描发起者）和 0:52（眨眼，160px 高，署名）出现，各 ≤ 24 帧进入，不循环。不改色、不拉伸、不加侧边附件、瞳孔保持竖条、轮廓不倒置。源文件 `src/renderer/public/brand/specloom.svg`。

## 质感

**不加噪点、不加纸纹贴图，纯平色块。** 官网也没有——加了反而和现有物料对不上。

## 风格帧与复现

三张静帧在 `design/promo-film/shots/`，由 `design/promo-film/style-frame.html` 渲染：

| 文件 | 覆盖内容 |
| --- | --- |
| `01-end-card.png` | 结尾标题版：132px 两行标题、CTA、字标、络络署名 |
| `02-read-paper.png` | 第 4 拍纸面态：四张真实资料卡、已读标记、扫描线、虚线连接 |
| `03-punch-in.png` | 对撞段：墨绿底、代码浮出、精灵绿强调 |

~~~powershell
node design/promo-film/render.mjs
~~~

脚本不只截图，同时做三件事并会在不满足时**非零退出**：

1. 每帧必须是精确 1920×1080，且内容不溢出；
2. 16 层文字按 WCAG 计算对比度，小于 24px 要求 4.5:1，大字要求 3:1；
3. 输出标题实测版心宽度。

当前结果：16 层全部通过，最低 3.91:1（代码注释行，38px 大字，要求 3.0）。

## 验收

1. 任取一帧，配色、字体、直角、1px 线都符合本文与 `docs/brand.md`。
2. 一帧里金色元素不超过 2 处。
3. 深色底只在 0:32–0:34 出现。
4. `node design/promo-film/render.mjs` 非零退出即视为风格退化。
