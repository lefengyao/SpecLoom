# SpecLoom 官网设计规格

日期：2026-10-11  
状态：首页视觉方向 A 已确认；用户已确认规格，进入实施计划。

## 目标

在仓库根目录的 `website/` 制作一个中文、响应式的官方产品介绍页，面向 Godot 和独立游戏开发者，清楚说明 SpecLoom 的定位与能力，并引导用户下载当前 Windows 版本。网站首版只在本机预览，不发布到公网。

`SpecLoom` 已有 Git 仓库，位于 `E:\生产项目\项目\TrailblazerStation\SpecLoom`。不再运行 `git init`，不重写历史，不触碰当前已有的未提交更改。

## 受众与产品信息

SpecLoom 是 Godot 优先、同时适用于普通代码项目的本地智能体开发工作区。官网内容以当前 0.1.6 版本为准：

- 在同一工作区维护项目规范、实体、组件和其他资料。
- 智能体可以结合项目资料、Skills、MCP 与编码工具完成开发任务。
- 管理 SpecLoom 截图桥和当前 Godot 项目的 EditorPlugin。
- 查看模型请求诊断信息，并通过 Trailblazer Hub 多开工作区。

桌面应用当前支持 Windows。官网不声称支持其他桌面平台，不宣称自动生成完整游戏，也不呈现未经验证的用户数、性能数字或在线服务。

## 视觉方向

采用用户从本地草图选定的 A「暖白编辑式」布局，并按后续反馈强化品牌识别：暖纸白作为大面积底色，深墨绿负责标题和阅读层级，青绿色品牌标记用于主按钮与知识关系图，赭金色作为纸张标记和索引的辅助色。以「Field Notes / 项目知识织图」为视觉线索，用工作区切片、关系连线、微型索引与不对称资料卡呈现 SpecLoom 的项目脉络感，避免常见的渐变 SaaS 模板。

首屏使用中文产品标题、一句说明、主下载按钮和次级功能入口；右侧展示标注为「界面示意」的工作区构图，内容准确呈现项目资料树、对话和工具链。标题与按钮优先保证桌面首屏可见；窄屏改为纵向排列，不横向溢出。

使用本地品牌 SVG，不从 CDN 加载字体、图片或脚本。使用系统中文无衬线字形搭配 Georgia 英文/数字标题；动效保持轻量，并尊重减少动态效果设置。

## 页面结构

1. **导航**：品牌标记、产品能力、工作流、版本下载入口；窄屏提供可键盘操作的折叠菜单。
2. **Hero**：产品定位、简短说明、Windows x64 0.1.6 下载 CTA、了解工作流入口，以及工作区界面示意。
3. **产品能力**：以真实能力为基础展示项目资料、智能体工具链、Godot 插件管理与截图桥、诊断日志和 Hub 多开。
4. **工作流**：按选择项目、读取项目上下文、执行并检查改动的顺序说明典型用法。
5. **版本下载**：明确展示 SpecLoom 0.1.6、Windows x64、安装版与便携版；下载地址走单独配置，不伪造公网发布地址。
6. **常见问题与页脚**：说明平台范围、Godot 优先方向、资料存储和 Trailblazer Hub 模块关系；提供有效的页内链接。

## 下载和本地预览

当前没有配置官网域名或公开发行地址。首版只支持本地预览，下载配置默认指向当前项目的 `release/0.1.6/` 安装程序和便携 ZIP。建议从 `SpecLoom` 根目录运行静态 HTTP 服务，通过 `/website/` 浏览，这样下载路径可访问相邻的 `release/`。后续如需公开发布，只需在独立配置中替换发行地址；本规格不包含上传、部署或购买域名。

下载链接只在对应的本地文件存在时显示为可用；不存在时展示清楚的本地预览提示，避免死链或伪造下载成功状态。

## Git 忽略规则

- 忽略整个 `/website/`，符合用户希望网站源码不进入当前 Git 跟踪范围的要求。
- 忽略 `/.runtime-user-data-fresh/`。它包含 Electron 缓存、偏好设置和近期项目列表，属于机器本地运行数据。
- 现有规则已覆盖 `node_modules/`、`build/`、`dist/`、`release/`、测试输出、日志和环境密钥，不增加重复或宽泛的忽略模式。
- 项目根部的 `%SystemDrive%/` 与 `NVIDIA Corporation/` 当前为空目录，Git 不跟踪空目录，无需添加规则。

## 实施边界

- 官网静态运行，不增加服务器端接口、账户、遥测或第三方脚本。
- 官网开发依赖与应用打包流程隔离；不影响 Electron renderer、应用图标、Hub 模块构建或 0.1.6 安装包。
- 不改写现有产品文档或历史版本发行文件，只新增官网内容与明确的忽略项。
- 保留工作区现有所有未提交更改，不暂存、不提交、不清理。

## 验收标准

- 桌面和手机视口均能清楚浏览，导航、页内跳转与菜单可用。
- 首屏呈现产品定位、工作区示意和 Windows 下载入口。
- 版本、平台与功能描述符合 SpecLoom 0.1.6；无法下载时有明确提示。
- 浏览器无资源加载错误、控制台错误、死链接或水平溢出；基本键盘访问与减少动态效果可用。
- `git check-ignore` 确认 `website/` 和本地用户数据目录被忽略，现有跟踪状态未被改变。

## 规格自检

- 不存在待定域名、公网地址或虚构下载源；对外部署被明确排除在首版之外。
- 下载文件、版本和 OS 的来源明确，且对本机缺失文件有设计好的显示状态。
- 网站被忽略与官网源码无法经当前仓库提交的结果一致，符合用户明确要求。
- 新忽略规则仅覆盖网站和包含本地个人状态的测试用户目录，未扩大到通用用户数据或源码。
