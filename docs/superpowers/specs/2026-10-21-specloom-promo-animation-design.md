# SpecLoom 一分钟宣传动画设计（01 / 内容）

日期：2026-10-21
状态：内容层已确认，进入撰写阶段前的定稿。
本文范围：**只定内容**（讲什么、按什么顺序讲、说什么话、屏幕上出现什么字）。视觉风格与镜头表是下一阶段产物，见文末「后续阶段」。

## 目标

做一支 60 秒宣传动画，投放于社交平台与产品发布，让 Godot / 独立开发者在一分钟内明白：

1. AI 的输入是项目里的真实资料，不是一段空白对话。
2. 这些资料是文件（Markdown + front matter），可读、可改、可追踪。
3. 动手有轨道：读写范围、人工审批、决策记录。

片名（工作名）：**《图纸活了》**。

## 已确定的前提

| 项 | 决定 | 理由 |
| --- | --- | --- |
| 时长 | 60 秒（1800 帧 @ 30fps） | 社交平台主片长度；可裁出 15 秒贴片 |
| 画幅 | 1920×1080，16:9 | 主投放为横屏；竖版衍生物不在本片范围 |
| 帧率 | 30fps | 图形动画足够，渲染成本低于 60fps |
| 语言 | 中文大字幕 + 少量英文技术标注 | 与 `docs/brand.md` 的等宽标注语言一致 |
| 声音 | 有声版，但**静音必须能看懂** | 社交平台大量静音播放 |
| 素材路线 | 矢量重绘，不用应用截图 | 截图无法干净地做进入/翻面/连线动画；截图留给 B 片 |

## 叙事主线

> AI 不认识你的世界，只能从零猜。SpecLoom 让你的世界先成为文件，AI 读过再动手。

开场用一句提问抓人，中段用真实项目文件把「世界」具体化，末段用一个左右对照把差异钉死。

## 世界与事实来源

片子使用应用内置的示例项目 **《灯塔守望》**（探索海岛与修复灯塔的 2D 游戏），片中出现的一切事实都来自它的真实文件，不做虚构数字：

| 片中呈现 | 来源 |
| --- | --- |
| 守灯人 `keeper`，玩家控制角色 | `specs/entities/characters/keeper.md` |
| 水平移动速度 180 | `keeper.md` 行为段 |
| 禁止增加战斗系统 | `keeper.md` 行为段（片中作为「约束」的例证） |
| 生成边界 `scenes/keeper.tscn`、`scripts/keeper.gd` | `keeper.md` 生成边界段 |
| 状态机基类：启用 / `current_state: idle` | `specs/components/state_machine.md` |
| Godot 4.4 · 2D · GDScript，脚本 ≤ 250 行，场景 ≤ 80 节点 | `specs/project.md` |
| 主场景 `res://scenes/main.tscn` | `.specloom/project.yaml` |
| 六个工作流节点：上下文 / 规划 / 实现 / 校验 / 人工审查 / 记录决策 | 「官方开发审查」默认工作流（6 节点 · 1 人工） |

「禁止增加战斗系统」是这支片子最重要的一行字：它是「AI 真的读过我的资料」的证据，比任何形容词都有力。

## 声音与音乐

- **旁白**：先用 TTS 占位以便排期，终版建议中性男声或沉稳女声。替换点是第 6 拍配音完成后整体对齐。
- **音乐**：约 105 BPM，三处卡点——0:14（图纸铺开）、0:30（睁眼+扫描）、0:52（收束成封面）。无授权素材时先用合成节拍垫底，素材到位后替换，不动画面时间码。
- **音效**（可选）：卡片落位的轻响、六节点点亮的逐声、结尾一次收束音。只在有素材时加，不为了让画面热闹而堆。

## 内容红线

- 不出现「赋能 / 革命性 / 重新定义 / 一站式」。
- 不出现无法核对的数字。片中所有数字都能在示例项目里找到。
- 不展示未实现的能力。片中出现的工作流节点、审批、`writePaths`、决策记录都对应 v0.1.9 的实际功能。
- 吉祥物「络络」只出镜两处（0:30 睁眼、0:52 眨眼），不抢产品。
- 结尾只给一个动作：下载 Windows 版。

## 验收标准

1. 静音观看一遍，能复述三个信息点中的至少两个。
2. 0–3 秒内出现明确提问，不需要铺垫就能知道这支片子在问什么。
3. 0:44 的左右对照，左右差异在两秒内可辨。
4. 结尾只有一个动作，没有并列的第二个 CTA。
5. 任取一帧，纸墨配色与等宽标注都符合 `docs/brand.md`。
