# 智能体工作区扩展

按用户本轮明确需求执行，取代此前“普通对话无工具”的方案。开发验证运行源码和 Vite 开发服务，不生成正式发行包，不变更版本，不提交已有工作。

## 设计

会话默认拥有项目工作工具；历史审查任务仍保留其审计数据，但不再决定聊天可用工具。文件修改使用读取回执与版本校验。工具按职责拆为文件、进程、任务/记忆、MCP、桌面控制和引擎插件。ToolSearch 按需加载工具描述，Skill 返回真实工作流正文，MCP 通过 SDK 发现并执行配置的服务器工具。

每个会话显示真实能力清单；每轮保留调用记录和统计。流式思考摘要独立于回答，等待模型与执行工具期间显示动画。个性化头像持久化，智能体默认品牌图。

Godot 4.7.1 stable 为首个插件目标；通过运行时桥接捕获游戏 Viewport，避免将其他窗口截图当作游戏截图。桌面控制单独实现，其他项目也能使用。
