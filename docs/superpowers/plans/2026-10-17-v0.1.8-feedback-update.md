```ts

// HTTP 集成中请求 bytes=2-4 时必须收到原文件的三个实际字节，不能只断言状态码。
```

## Task 7: 建立真实只读 Git/项目文档概览

**Create:** `src/main/core/project-overview.ts`、`src/main/core/git-query.ts`。
**Modify:** `src/main/desktop-controller.ts`、`src/main/ipc.ts`、`src/main/preload.ts`。

- [x] **Step 1: git-query 使用 execFile/spawn 参数数组，shell:false，固定 cwd 和环境。** 查询使用以下固定子命令；不拼入用户命令，不调用 fetch/push/status hooks：

```text
git rev-parse --is-inside-work-tree --is-bare-repository
git rev-parse --show-toplevel
git rev-parse --git-dir --git-common-dir
git symbolic-ref --quiet --short HEAD
git rev-parse --verify HEAD
git for-each-ref --format=%(refname)%00%(refname:short)%00%(HEAD)%00%(upstream:short)%00%(symref) refs/heads refs/remotes
git config --null --get-regexp ^remote\..*\.(url|pushurl)$
```
