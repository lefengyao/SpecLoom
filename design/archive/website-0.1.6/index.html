常见问题

开始之前

关于支持范围与 SpecLoom 当前定位的简要说明。

SpecLoom 支持哪些系统？

目前仅支持 Windows x64，提供安装程序与便携版两种发行包。

除了 Godot，SpecLoom 也适用于普通代码项目吗？

Godot 项目是优先场景，也可用于普通代码项目，整理项目资料并配置 Skills、MCP 与工具。Godot EditorPlugin 和截图桥能力适用于 Godot 项目。

项目资料和 Skills 保存在哪里？

项目规范、实体、组件等资料保存在项目的 specs/ 目录；项目 Skills 位于 .specloom/skills/，内部历史位于 .specloom/history/。

Trailblazer Hub 模块版如何与独立版及多开配合？

Trailblazer Hub 0.1.6 或更新版本可加载 SpecLoom 模块；每次点击「启动」都会打开新窗口，支持多开。模块版与独立版可打开已有项目，但各自使用独立的全局设置。
