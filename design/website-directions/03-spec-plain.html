SECTION 01 / OVERVIEW

项目上下文，
是一种基础设施。

SpecLoom 是一个本地优先的 Godot 项目工作区。规范、实体、组件、Skills 与工具围绕同一份项目上下文展开，让智能体在动手之前先读懂现场。

SECTION 02 / CAPABILITIES

能力清单。

五项能力围绕同一个项目现场展开。资料是输入，智能体是执行者，编辑器与运行画面是验证现场。

  1. 01

    项目资料

    规范、实体、组件、设定、地图与 UI 各自成文；保留父级、继承和字段，页面与智能体读取同一份内容。

    specs/entities/
  2. 02

    智能体运行时

    会话携带项目资料、Skills、MCP 与编码工具；读取、修改、验证围绕当前项目发生。

    agent / runtime
  3. 03

    Godot 连接

    查看与启停项目内的 EditorPlugin；启用截图桥后，智能体可读取运行中的游戏视口。

    EditorPlugin
  4. 04

    执行可见

    公开进度气泡、工具步骤与每轮文件变化按顺序展开；模型请求可按诊断编号检索。

    diagnostics
  5. 05

    多工作区

    通过 Trailblazer Hub 打开多个 SpecLoom 窗口；不同项目的会话、草稿与运行状态彼此独立。

    hub / multi-window

SECTION 03 / PROCEDURE

三步，接上现场。

从打开现有项目开始。SpecLoom 沿着资料与代码把上下文串起来，再由你决定下一步。

01SELECT

选择项目

打开 Godot 项目或普通代码项目，读取项目结构、资料目录与已配置的工具。

OUTPUT → PROJECT LOADED
02READ

读取项目上下文

规范、实体、组件、Skills 与 MCP 进入同一份上下文，智能体先理解再提出建议。

OUTPUT → CONTEXT READY
03REVIEW

执行并检查改动

推进任务、查看工具步骤与本轮文件变化；需要审批的写入仍由你确认。

OUTPUT → CHANGES REVIEWED
