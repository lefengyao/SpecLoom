SpecLoom adaptations: the WebSocket client requires the `specloom` service identity and exact normalized project path during handshake; the command router exposes exactly the eight read-only routes listed in SpecLoom's Godot MCP documentation. The upstream gameplay timer that automatically closed editor dialogs and popups has been removed.
